# Hey, I'm cleverridge70768

I spend most of my time writing Python scripts that make repetitive tasks disappear. Whether it's batch renaming files, scraping data from half-broken APIs, or stitching together small tools that run on a headless Linux box, automation is the thread that runs through almost everything I do.

## What I care about

**Python** is still my daily driver. I like keeping things simple — plain scripts, a few well-chosen libraries, and enough comments that future-me doesn't curse past-me. When something needs to run unattended for weeks, I lean on systemd timers or cron and keep the logs readable.

**Linux** is the environment I trust. Most of my experiments live on a small VPS or an old laptop that never gets turned off. Package management, shell pipelines, and the ability to dig into `/proc` when something feels off are part of the reason I stay here.

**Open source** is how I learn. I read other people's code more than I write my own. Contributing small fixes, documenting weird edge cases, and occasionally shipping a utility that someone else finds useful feels better than chasing stars.

## Current focus

Right now I'm tightening a set of small automation helpers that watch directories, process files as they appear, and push summaries to a local dashboard. Nothing fancy, just reliable. I'm also spending time reading source from projects I rely on daily so I understand the trade-offs they made.

If you maintain something in the Python or Linux tooling space and need an extra pair of eyes on an issue or a PR, feel free to tag me. I'm usually around.
